# NEXORA AI CAMERA

Android AI-assisted camera project. The Android Studio source archive is stored temporarily at `.bootstrap/NexoraAICamera.zip.b64`; the GitHub Actions workflow extracts it before building.

## Build
Open **Actions → Build NEXORA AI CAMERA APK**. A push to `main` also starts the build. After a successful run, download the `NexoraAICamera-debug-apk` artifact.

The APK is a debug build for testing, not a Play Store release-signed APK.
